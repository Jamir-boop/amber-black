# Amber UI concepts

The selected written guides are dark and amber-only:

- [01 Soft Amber](../soft-amber.md): warm dark charcoal and soft amber.
- [02 Honey Graphite](../honey-graphite.md): dark graphite and muted honey gold.
- [09 Honey Mist](../honey-mist.md): a dark adaptation with honey surfaces.

All three selected guides keep canvases, panels, fields, menus, dialogs, and
code surfaces dark. They have no white or light mode or light fallback.
Image 09 remains the earlier light illustration. Its exact prompt history
remains unchanged. The selected Honey Mist guide supplies new dark values.

Open [the image gallery](index.html) to compare all ten generated UI concepts.

ImageGen generated these images with synthetic task content. The colors show
the intended direction approximately. Exact pixels and text are generative.
These concepts do not establish WCAG compliance, working controls, or a live app.

See [prompts.json](prompts.json) for the exact generation prompts and source
image paths. The selected Markdown tables are the exact token specification;
the images do not prove those values or native state behavior.
